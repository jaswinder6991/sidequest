# SideQuest visual direction

## Cinematic historical reconstruction

Every generated image should feel like a frame from the same film: an intimate,
atmospheric reconstruction of a real moment hidden beneath present-day
Barcelona.

- Preserve the actual architecture and street scale.
- Use period-accurate people, objects, and lighting when depicting the past.
- Prefer a single compelling moment over an illustrative collage.
- Keep the composition vertical and leave calm space for the SideQuest story UI.
- Make history emotionally present without turning trauma into spectacle.
- Never add text, logos, watermarks, split screens, or generic fantasy imagery.
